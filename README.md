# Support Ticket System

A backend project developed in **Python** to build practical knowledge in **APIs, databases, backend development, and software architecture**.

The project is being developed as a learning and portfolio project, with the goal of applying programming fundamentals to a system closer to a real-world software solution.

## Version

**V.01 — Project Initialization**

The current version represents the initial stage of the project.

At this stage, the main objective is to define the system's purpose, architecture, requirements, and technologies that will be used throughout its development.

## Project Objective

The objective of this project is to develop a **Support Ticket System** capable of managing support requests from their creation to their resolution.

The system will be designed around concepts commonly found in real-world support and service management systems, such as:

- Ticket creation and management
- Ticket status
- Priority levels
- Categories
- Users
- Ticket history
- Data persistence
- Business rules
- REST API communication

The project will gradually evolve as new concepts and technologies are introduced.

## Knowledge Applied

This project will be used to develop and reinforce practical knowledge in several areas of software development.

### Python

Python will be the main programming language used throughout the project.

The project will reinforce concepts such as:

- Variables and data types
- Conditional statements
- Loops
- Functions
- Exception handling
- Modules and packages
- Object-oriented programming
- Data structures
- Code organization

### REST API

The project will introduce the development of a RESTful API using **FastAPI**.

Concepts to be studied and applied include:

- HTTP methods
- Endpoints
- Request and response handling
- HTTP status codes
- JSON
- Data validation
- API architecture
- CRUD operations
- API documentation

### Database

A relational database will be used to store and manage the application's data.

The initial development will use **SQLite**, allowing database concepts to be introduced gradually.

Knowledge to be applied includes:

- Tables
- Records
- Primary keys
- Foreign keys
- Relationships
- SQL queries
- CRUD operations
- Data persistence
- Database modeling

### Backend Development

The project will introduce concepts related to backend development, including:

- Application architecture
- Separation of responsibilities
- Business logic
- Data access
- Error handling
- Validation
- API and database integration

### Software Development Practices

The project will also be used to practice development workflows and code quality practices, including:

- Git
- GitHub
- Version control
- Project documentation
- Incremental development
- Code organization
- Testing

## Development Approach

The system will be developed incrementally.

Each version will introduce new functionality and concepts while maintaining the knowledge acquired during previous stages.

The initial priority is not to build a complex system as quickly as possible, but to understand **how the different components of a backend application work together**.

```text
Python
   ↓
FastAPI
   ↓
REST API
   ↓
Business Logic
   ↓
Database
   ↓
SQL
```
